terraform init  .................Initializes terraform for the providers you mentioned in the .tf file
terraform init -upgrade .........When we do terraform init it eill lock the provider version in terraform,lock.hcl file, if we want to update the version in lock file use this command
terraform init -migrate-state
terraform init -reconfigure

terraform version   .............Shows version of the terraform installed on your machine

terraform plan  .......................................................Shows a description of the config you are trying to create
terraform plan -refresh=false   .......................................By default terraform refresh will happen with plan and apply command to avoid this you can set the -refresh flag as false while running plan and apply
terraform plan -out file_name.plan  ...................................It stores the plan into the file in binary format, which can be use create resource using terraform apply
terraform plan -target="resource_type.resource_name"    ...............With target flag it allow us to plan specific resource
terraform plan -var-file="file_name.tfvars" ...........................It will create plan using values define for varibles in the *.tfvars file
terraform plan -var="variable_name=value"   ...........................It will define the value of the variable declared in tf file from command line
terraform plan -var="variable_name=value" -var="variable_name=value" ..For defining value for more than one variable from CLI

terraform apply .......................................................It will create all the new resources mentioned in the .tf file
terraform apply -auto-approve   .......................................No need to confirm again by typing yes, it will create all the resources
terraform apply -target="resource_type.resource_name"   ...............With target flag it allow us to create specific resource
terraform apply -target="resource_type.resource_name" -auto-approve ...With target flag it allow us to create specific resource and auto approves it
terraform apply -replace="resource.resource_name"   ...................It will replace the resource object even though there is no changes. It will first destroy older EC2 and than create new EC2
terraform taint .......................................................Older version of above command not to use as its deprecated
terraform apply "file_name.plan"    ...................................To create a resource with a .plan file use this command 

terraform destroy   ...................................................It will destroy all the resources mentioned in the .tf file
terraform destroy -auto-approve .......................................No need to confirm again by typing yes, it will destroy all the resources
terraform destroy -target="resource_type.resource_name" ...............With target flag it allow us to destroy specific resource
terraform destroy -target="resource_type.resource_name" -auto-approve .With target flag it allow us to destroy specific resource and auto approves it

terraform refresh   .................It will check the latest state of infra and update the terraform.tfstate file accordingly
terraform console   .................It provides an interactive environment to run terraform code in CLI

terraform fmt   ..................It rewrite the terraform config file to take care of the overall formatting
terraform fmt -check    ..........It will just check if file is formatted it will not modify the file
terraform fmt -recursive    ......It will format terraform files that are present within the directory and also child directories

terraform validate  .............It check whether terraform file is syntatically valid. It can check unsupported args, undeclared varibles and more

terraform graph ...............................It will generate output in graph language to convert this into image use online websites or download application
terraform graph | dot -Tpng >graph.png  .......Download graph viz locally and run this command. It generates graph code and pass it to dot to generate png image

terraform show file_name.plan   ...............To see terraform .plan file use this command
terraform show -json file_name.plan ...........It will print .plan file content in json
terraform show -json file_name.plan | jq    ...It will print .plan file content in json and will be formatted using jq application

terraform output output_variable_name   .......It is used to extract value of output variable from the state file
terraform force-unlock lock_id ................It is used to unlock the state file forcefully to allow write operations

terraform state list    ..............................It will list resources in the state file
terraform state pull    ..............................It will manually download and output resources of the remote state
terraform state push    ..............................It manually uploads a local state file to remote state
terraform state rm resource_type.resource_name........It removes items from the terraform state file, it gets removes from terraform state management without destroying the resource
terraform state show resource_type.resource_name   ...It shows attributes of a single resource in the state
terraform state replace-provider source_provider target_provider    ..................It is use to replace provider for the resource in a terraform state
terraform state mv source_resource_type.resource_name target_resource_type.resource_name  ..................................It moves items with terraform state file

terraform workspace show    .................It will show the name of the current workspace
terraform workspace new workspace_name  .....It will create a new workspace and switch to it
terraform workspace list    .................It will list all the workspace available
terraform workspace select workspace_name  ..To switch between workspace use this command
terraform workspace delete  workspace_name ..It will delete the workspace
